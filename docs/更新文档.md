## 最新版本

### v1.7.0（2026-09）—— 提醒通知 · 趋势分析 · 光疗照片

**新增功能**
- 任务提醒通知：任务可设「提前 N 分钟提醒」（不提醒/5/30/60 分钟/自定义），Android 定时通知 + 开机恢复，完成自动取消、撤销自动重建
- 趋势分析：自绘折线图（无图表库依赖），光疗剂量趋势（红斑/水疱异常标记）+ 测量值趋势，含目标范围参考带与点击 tooltip
- 光疗照片记录：拍摄引导 checklist（同角度/同距离/同光线/患处可见），拍照/相册，照片时间线（缩略图 + 全屏查看）

**数据变更**：schema v6 → v7（`tasks.remindBeforeMinutes`、`care_photos` 表）

**验证**：analyze 无问题，79/79 测试通过（新增 20）

## 历史版本

### v1.6.0（2026-09）—— 光疗记录 · 手动事件 · 档案完善 · 逾期关注

**新增功能**
- 308nm 光疗结构化记录：部位/左右侧/剂量/单位/红斑/疼痛/瘙痒/灼热/水疱/备注，疾病详情页光疗记录区
- 手动健康记录（§7 Event First）：测量（指标/数值/单位）/症状/用药/治疗/自定义，写入统一事件
- 患者档案完善：性别、出生日期编辑
- 疾病状态管理：长按切换管理中/缓解期/已痊愈
- 首页「需要关注」区：逾期任务警告卡

**数据变更**：schema v5 → v6（`phototherapy_records` 表）

**验证**：analyze 无问题，59/59 测试通过（新增 14）

### v1.5.0（2026-09）—— 任务备注与撤销

**新增功能**
- 任务备注：完成时可带备注（剂量/感受），事件与任务双记录，事后可补写，时间线展示
- 撤销完成：任务恢复待办，删除完成事件与派生的下一次任务/24h 反应任务，链可重新开始

**数据变更**：schema v4 → v5（`tasks.notes`、`events.taskId`）

**验证**：analyze 无问题，45/45 测试通过（新增 5）

### v1.4.0（2026-09）—— 计划与任务概念对齐 FHIR

**变更**
- 三层模型：PlanDefinition（模板）→ CarePlan（计划实例）→ Task（任务实例）
- 模板点击先实例化管理计划，再由计划生成任务链；任务链全程带 carePlanId
- 计划生命周期控制：暂停/完成后不再生成下一次任务

**数据变更**：schema v3 → v4（`care_plans.templateId`）

**验证**：analyze 无问题，40/40 测试通过

### v1.3.0（2026-09）—— iOS 26 tint 风格多配色主题

**新增功能**
- 5 套强调色：海盐蓝（默认）/薰衣草紫/薄荷青/珊瑚暖橙/鼠尾草绿，低饱和医疗适配
- 明暗 × 配色自由组合；暗色模式自动使用品牌高亮色
- 设置页外观卡配色选择器，持久化重启保持

**验证**：analyze 无问题，38/38 测试通过（新增 1）

### v1.2.0（2026-09）—— 疾病差异化适配

**新增功能**
- 医学知识库（循证条目，来源可追溯）：加拿大白癜风共识 2025、ADA 标准 2025
- 任务周期引擎：daily / weekly（星期集合+锚点周）/ monthly，疗程结束日期，纯函数可测
- 疾病模板：308nm 光疗（每周一三五）、HbA1c 每 3 个月、年度综合检查
- 完成周期任务自动生成下一次；光疗完成后 24h 生成皮肤反应记录任务

**数据变更**：schema v2 → v3（任务周期字段）

**验证**：analyze 无问题，37/37 测试通过（新增 17）
