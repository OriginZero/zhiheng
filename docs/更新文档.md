> **规则：本文档只做线性追加，永不改写历史条目。**
> 每次发布版本在「最新版本」之后追加一节，旧条目保持原样。
> 格式：版本号（tag）→ 日期 → 变更内容 → 验证结果。

---

## 版本规范速查

- 版本格式：`major.minor.patch+build`；**大功能 → major+1，中等功能 → minor+1，小功能/修复 → patch+1，每次发版 build+1**。
- 发版前运行 `bash tool/check_release.sh` 校验；版本号必须与 git tag 一致。
- 完整规则见 docs/约束性文档.md「9. 版本管理」。

### v1.11.0（2026-09-04）—— 管理计划生命周期修复 · 档案身体数据可选项（pre）
- 同模板计划可重复创建：模板卡创建前按「患者 × 模板」查询，已有计划（任意状态）即提示去「管理计划」区暂停/恢复/删除，不再重复创建；另加创建在途连点锁防并发双插
- 计划暂停后无法恢复：暂停态新增「恢复计划」；暂停 = 停止生成新任务 + 取消未完成任务提醒；恢复 = 重新置 active + 重建提醒，暂停期间链已空（任务已全部完成）时按当前时间重新锚点生成下一条；疗程已结束且链空则提示删除后重建，不再超疗程生成
- 计划无法删除：全部状态（进行中/已暂停/已完成）提供「删除计划」，删除前弹确认对话框——**已有完成记录/执行补充/照片时明确提示「历史保留，仅删除计划本身与未完成任务」**，时间线事件与照片永不随计划删除（历史不可变 §44）
- 计划停止级联问题：暂停/恢复/完成/删除全部按 **planId 单计划作用域**执行（仓储新增 pauseCarePlan/resumeCarePlan/completeCarePlan/deleteCarePlan + 单计划提醒副作用），根因（同模板重复计划共享排程）由防重规则从源头杜绝；历史重复计划可经删除清理
- 完成计划从「仅改状态」补齐为：停止生成 + 清理未完成任务提醒（确认对话框后执行）
