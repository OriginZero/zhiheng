# 知衡数据模型文档

> 本文档描述本地数据库（drift / SQLite）schema 与领域模型。
> schema 变更（新增表/列/迁移）后必须同步更新本文档。

---

## 1. 总览

- 存储引擎：drift 2.34（SQLite）
- 当前 schema 版本：**v8**（`AppDatabase.schemaVersion`）
- 迁移策略：`MigrationStrategy.onCreate/createAll` + `onUpgrade` 逐版本迁移；历史数据保留（§44）
- 所有表带 `createdAt` / `updatedAt`（历史不可变 + 未来同步预留，§20）
- ID 统一 UUID v4（`newId()`）

## 4. 领域模型（lib/shared/domain/）

`domain.dart` barrel 导出：Patient / Disease / CarePlan / Task / Reminder / HealthEvent / TaskRecurrence / PhototherapyRecord / CarePhoto 及全部枚举（Gender、DiseaseStatus、CarePlanStatus、TaskType、TaskSource、TaskPriority、TaskStatus、EventType、EventSource、ReminderStatus、RecurrenceFrequency、BodyLaterality、PhotoKind）。

领域模型 ↔ Drift 行映射集中在 `local_repository.dart`（`*FromRow` 函数），UI 层只接触领域模型（§41）。
