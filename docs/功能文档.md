## 2. 功能清单

### 2.1 首页（Today，§31）

- **问候语**：按时段问候 + 患者名字 + 当日日期
- **需要关注区**：逾期未完成任务警告卡（数量 + 最多 3 条标题），无逾期不显示
- **疾病卡片区**：横滑展示疾病卡片（点击进详情），空时显示引导卡
- **今日管理**：按「必须完成 / 建议完成」分组展示当日任务；勾选完成；「+」添加任务；「记录」打开手动事件表单
- **近期待办**：未来 7 天待办（最多 3 条）

### 2.2 任务（§10、§11）

- **创建**：标题、类型（用药/治疗/测量/拍照/运动/复诊/记录/自定义）、优先级（必须/建议）、日期时间、提醒（不提醒/提前 5/30/60 分钟/自定义）、可选关联疾病
- **周期任务**：每日 / 每周（星期几集合，锚点周计数）/ 每月；疗程结束日期；完成自动生成下一次
- **来源可追踪**：医生方案 / 临床规则 / 管理计划 / 用药计划 / 监测计划 / 自建
- **备注**：完成时可带备注（剂量、感受），事后可补写，时间线同步展示
- **执行补充记录**（v1.8）：勾选 308nm 光疗任务时可按治疗部位补充照射时长（分/秒，如 1 分半）与部位照片（患处照）；以 JSON schema 存储（`vitiligo.phototherapy.exposure.v1`），疾病/模板差异可新增 schema 扩展，存储层不感知结构
- **应用上一次记录**（v1.8.1）：同模板存在历史补充时，光疗完成弹层顶部出现「应用上一次记录（日期）：部位摘要」按钮，一键带入上次的部位名称与照射时长（短周期内治疗部位/时长通常不变，方便快速填写）；照片**不**复用（每次治疗需重新拍摄才反映当前皮肤状态）；已有输入时先确认替换
- **检查单据照片**：勾选糖尿病「复查 HbA1c / 年度糖尿病综合检查」任务时弹出「记录检查结果」表单，可拍摄 / 从相册上传**多张**本次检查报告 / 化验单照片（单据拍摄引导：完整入镜 / 字迹清晰 / 无反光 / 方向端正）；照片关联任务保存（care_photos.taskId，任务详情可全屏查看与删除），补充记录 schema `diabetes.check.report.v1`；单据非必填，没有单据也能直接完成任务
- **撤销**：撤销完成 → 任务恢复待办，清理完成事件与派生的下一次任务/反应任务；**保留备注与执行补充记录**（误撤销不丢数据），只有用户主动删除补充记录（任务详情弹层「删除记录」）才丢弃（含关联照片）
- **任务详情弹层**：状态、类型、时间、来源、周期元信息、描述、备注编辑、撤销入口；执行补充照片缩略图点击可全屏查看原图

### 2.3 疾病管理（§6）

- 添加疾病：内置白癜风、2 型糖尿病 + 自定义
- 疾病详情页：
  - **指南推荐模板**（依据展示 + 一键创建计划）：白癜风 308nm 光疗（每周一三五）；糖尿病空腹血糖（每日）、餐后2小时血糖（每日）、睡前血糖（每日）、HbA1c 复查（每 3 个月）、年度综合检查（每 12 个月）
  - 模板创建后**立即从今天开始**：首次任务即当前时刻，出现在首页今日管理
  - 血糖任务完成时弹出「记录本次血糖」表单：血糖值、测量方式（指尖/CGM/医院）、症状多选、运动前后开关；血糖 <3.9 mmol/L 自动标记低血糖并高亮警告（1 级 <3.9、2 级 <3.0，依据《中国糖尿病防治指南（2024版）》）。糖尿病「复查 HbA1c」「年度综合检查」任务完成时弹出「记录检查结果」弹层：可上传本次检查报告 / 化验单照片（多张）。血糖、光疗、糖尿病检查的完成记录弹层共用**通用外壳 `RecordCompletionSheet`**（shared/widgets）：统一 M3 弹层（标题/说明/备注/字段滚动 + 底部按钮钉底）/「保存并完成」+「仅完成，不记录本次细节」/busy 与结果返回，各模块只提供中间字段区与提交逻辑，新疾病模块可直接复用
  - 光疗任务在**非计划日勾选**（提前完成/补做）→ 提示用户，确认后按**实际治疗日重排后续任务**（保持每周 2～3 次的模板节奏、两次间隔 ≥2 天），24h 皮肤反应记录任务同样按实际完成时刻生成
  - 管理计划：创建（**同模板防重复**：同一疾病同一模板仅允许一份计划，重复点击提示去管理计划区操作）、暂停（停止生成新任务并取消提醒）/ 恢复（重新排程并恢复提醒；空链时从当前时间重新锚点；疗程已结束则提示删除重建）/ 完成（终态，停止生成并清理未完成任务提醒）/ **删除**（级联移除未完成任务；**已有完成记录/照片时对话框明确提示「历史保留，仅删计划本身」**，时间线/照片永不随计划删除）；计划操作一律按 planId 隔离，不影响其它计划；周期/疗程展示
  - 待办任务
  - **光疗记录**（仅白癜风）：部位/左右侧/剂量/单位/红斑/疼痛/瘙痒/灼热/水疱/备注
  - **剂量趋势**（仅白癜风）：最近 30 次剂量折线，红斑/水疱异常标记
  - **测量趋势**：测量事件数值折线
  - **照片时间线**（仅白癜风）：治疗前后/患处照片，拍摄引导；所有照片缩略图（时间线 / 任务详情执行补充 / 光疗完成表单）点击全屏查看原图（可缩放，含拍摄引导通过项）
  - 勾选类控件（任务完成圈 / 勾选框 / 单选）统一放列表行**左侧**（单手握持优先；照片等覆盖语义除外）


### 2.X 糖尿病专属首页（v1.9.0）

- **今日血糖**：展示当日血糖任务（空腹/餐后2小时/待完成），勾选打开血糖记录弹层
- **快速记录**：不关联任务，直接记录一次血糖（写入测量事件）
- **低血糖预警**：最近一次血糖 <3.9 mmol/L 时顶部高亮横幅（严重 <3.0 标红）
- **血糖趋势**：近 30 次血糖折线图，3.9 mmol/L 低血糖参考线
- 路由：`/disease/:id/diabetes`（从疾病详情页或疾病卡片进入）

### 2.4 医疗时间线（§9）

- 全部事件按日期分组倒序展示
- 按疾病、事件类型过滤
- 事件卡：图标、标题、时间、类型标签、备注气泡（概述：光疗补充只展示部位/时长/照片数量摘要，最多 3 行省略）
- **查看详情**（v1.8.1）：关联任务的事件卡可点击，打开任务详情弹层查看部位/时长/照片等完整细节
- 历史脏数据兼容（v1.8.1）：v1.8.0 摘要插值 bug 写入的「Instance of …」文本在展示层清洗，事件本身不改写（§44）
- 数据来源：任务完成事件、手动记录事件

### 2.5 手动健康记录（§7 Event First）

- 类型：测量（指标/数值/单位入 payload）/ 症状 / 用药 / 治疗 / 自定义
- 标题、备注、时间（默认现在）、可选关联疾病
- 写入统一 Events 表，进入时间线

### 2.6 提醒通知（§11）

- 链路：CarePlan → Task → Reminder → Notification
- 任务「提前 N 分钟」提醒设置
- 完成自动取消提醒；撤销恢复待办自动重建
- 应用启动补发到期提醒；Android 定时通知接收器 + 开机恢复

### 2.7 患者档案与设置

- 档案：姓名、性别（女/男/其他/未填写）、出生日期（日期选择器）、身体数据可选项（体重 kg / 身高 cm，v1.11.0 起，均不强制，未填写不展示）
- 主题：明暗（跟随系统/浅色/深色）× 强调色（海盐蓝/薰衣草紫/薄荷青/珊瑚暖橙/鼠尾草绿/海军蓝/翡翠绿/暖沙/靛蓝）
- 疾病管理入口、医疗安全说明

### 2.8 医学知识库（§13）

已收录循证条目（来源可追溯）：

| 条目 | 依据 | 要点 |
|---|---|---|
| 白癜风光疗建议 | 加拿大白癜风管理共识 2025 | 初始每周 2–3 次，疗程 6–12 个月，维持每周 1–2 次 |
| 白癜风光疗建议 | 白癜风诊疗共识 2024（中华皮肤科杂志 2024;57(12)） | 308nm 每周 2–3 次，起始剂量参考 NB-UVB 方案 |
| HbA1c 监测 | ADA 标准 2025 | 未达标每 3 个月，达标稳定每 6 个月 |
| 糖尿病年度评估 | ADA 标准 2025 | 血压/血脂/肾功/眼底/足部每年综合评估 |
| 糖尿病血糖自我监测 | 中国糖尿病防治指南 2024 | SMBG 频率按病情决定；时点：空腹/餐前/餐后2h/睡前/夜间 |
| 糖尿病低血糖 | 中国糖尿病防治指南 2024 | 1 级 3.0≤血糖<3.9；2 级 <3.0；3 级需他人帮助 |
