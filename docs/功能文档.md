## 2. 功能清单

### 2.1 首页（Today，§31）

- **问候语**：按时段问候 + 患者名字 + 当日日期
- **需要关注区**：逾期未完成任务警告卡（数量 + 最多 3 条标题），无逾期不显示
- **疾病卡片区**：横滑展示疾病卡片（点击进详情），空时显示引导卡
- **今日管理**：按「必须完成 / 建议完成」分组展示当日任务；勾选完成；「+」添加任务；「记录」打开手动事件表单
- **未来任务**：未来 7 天待办（最多 3 条）

### 2.2 任务（§10、§11）

- **创建**：标题、类型（用药/治疗/测量/拍照/运动/复诊/记录/自定义）、优先级（必须/建议）、日期时间、提醒（不提醒/提前 5/30/60 分钟/自定义）、可选关联疾病
- **周期任务**：每日 / 每周（星期几集合，锚点周计数）/ 每月；疗程结束日期；完成自动生成下一次
- **来源可追踪**：医生方案 / 临床规则 / 管理计划 / 用药计划 / 监测计划 / 自建
- **备注**：完成时可带备注（剂量、感受），事后可补写，时间线同步展示
- **执行补充记录**（v1.8）：勾选 308nm 光疗任务时可按治疗部位补充照射时长（分/秒，如 1 分半）与部位照片（患处照）；以 JSON schema 存储（`vitiligo.phototherapy.exposure.v1`），疾病/模板差异可新增 schema 扩展，存储层不感知结构
- **撤销**：撤销完成 → 任务恢复待办，清理完成事件与派生的下一次任务/反应任务；**保留备注与执行补充记录**（误撤销不丢数据），只有用户主动删除补充记录（任务详情弹层「删除记录」）才丢弃（含关联照片）
- **任务详情弹层**：状态、类型、时间、来源、周期元信息、描述、备注编辑、撤销入口

### 2.3 疾病管理（§6）

- 添加疾病：内置白癜风、2 型糖尿病 + 自定义
- 疾病详情页：
  - 当前状态（管理中/缓解期/已痊愈，可长按切换）
  - **指南推荐模板**（依据展示 + 一键创建计划）：白癜风 308nm 光疗（每周一三五）、HbA1c 复查（每 3 个月）、年度综合检查（每 12 个月）
  - 模板创建后**立即从今天开始**：首次光疗任务即当前时刻，出现在首页今日管理
  - 光疗任务在**非计划日勾选**（提前完成/补做）→ 提示用户，确认后按**实际治疗日重排后续任务**（保持每周 2～3 次的模板节奏、两次间隔 ≥2 天），24h 皮肤反应记录任务同样按实际完成时刻生成
  - 管理计划：创建、暂停、完成；周期/疗程展示
  - 待办任务
  - **光疗记录**（仅白癜风）：部位/左右侧/剂量/单位/红斑/疼痛/瘙痒/灼热/水疱/备注
  - **剂量趋势**（仅白癜风）：最近 30 次剂量折线，红斑/水疱异常标记
  - **测量趋势**：测量事件数值折线
  - **照片时间线**（仅白癜风）：治疗前后/患处照片，拍摄引导

### 2.4 医疗时间线（§9）

- 全部事件按日期分组倒序展示
- 按疾病、事件类型过滤
- 事件卡：图标、标题、时间、类型标签、备注气泡
- 数据来源：任务完成事件、手动记录事件

### 2.5 手动健康记录（§7 Event First）

- 类型：测量（指标/数值/单位入 payload）/ 症状 / 用药 / 治疗 / 自定义
- 标题、备注、时间（默认现在）、可选关联疾病
- 写入统一 Events 表，进入时间线

### 2.6 提醒通知（§11）

- 链路：CarePlan → Task → Reminder → Notification
- 任务「提前 N 分钟」提醒设置
- 完成自动取消提醒；撤销恢复待办自动重建
- 应用启动补发到期提醒；Android 定时通知接收器 + 开机恢复

### 2.7 患者档案与设置

- 档案：姓名、性别（女/男/其他/未填写）、出生日期（日期选择器）
- 主题：明暗（跟随系统/浅色/深色）× 强调色（海盐蓝/薰衣草紫/薄荷青/珊瑚暖橙/鼠尾草绿）
- 疾病管理入口、医疗安全说明

### 2.8 医学知识库（§13）

已收录循证条目（来源可追溯）：

| 条目 | 依据 | 要点 |
|---|---|---|
| 白癜风光疗建议 | 加拿大白癜风管理共识 2025 | 初始每周 2–3 次，疗程 6–12 个月，维持每周 1–2 次 |
| HbA1c 监测 | ADA 标准 2025 | 未达标每 3 个月，达标稳定每 6 个月 |
| 糖尿病年度评估 | ADA 标准 2025 | 血压/血脂/肾功/眼底/足部每年综合评估 |

## 3. 技术栈与架构

- Flutter 3.47.2（mise 管理，版本锁定在 `mise.toml`）
- 状态管理：flutter_riverpod 2.6
- 路由：go_router 18（ShellRoute + 玻璃底部导航）
- 本地存储：drift 2.34（SQLite，schema v7，含迁移）
- 通知：flutter_local_notifications
- 图片：image_picker
- 目录：`lib/{app,core,features,shared}` Feature-based 架构
- 数据流：UI → Notifier → Repository → Drift
