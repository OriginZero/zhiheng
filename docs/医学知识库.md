## 1. 收录条目

### 1.1 白癜风：308nm / NB-UVB 光疗建议

- **来源类型**：专家共识
- **文献**：Canadian Consensus Guidelines for the Management of Vitiligo（加拿大白癜风管理共识）
- **组织**：加拿大皮肤病学会等（J Eur Acad Dermatol Venereol 发表）
- **日期**：2025-06（PMID 40253664，PMC12092322）
- **疾病**：vitiligo
- **推荐要点**：
  - NB-UVB 与 308nm 准分子激光/光为推荐光疗方式
  - **初始：每周 2–3 次**，直到充分复色
  - **疗程通常 ≥ 6–12 个月**；6–12 个月后评估是否继续
  - 达到充分复色后可改为**维持治疗（每周 1–2 次）**；维持治疗降低复发风险
  - 诊所监督优于家用设备
- **产品中的使用**：光疗模板默认每周一/三/五（每周 3 次，取指南上限区间内值），疗程默认 6 个月；UI 提示「具体剂量与频率以医生方案为准」
- **代码位置**：`KnowledgeBase.entries` id `vitiligo.phototherapy.frequency`；`DiseaseTemplates.all` id `vitiligo.phototherapy`

### 1.2 2 型糖尿病：HbA1c 监测频率

- **来源类型**：临床指南
- **文献**：ADA Standards of Care in Diabetes—2025（第 6 章 Glycemic Goals and Hypoglycemia）
- **组织**：American Diabetes Association
- **日期**：2024-12（Diabetes Care 2025;48(Suppl 1)，DOI 10.2337/dc25-S006）
- **疾病**：type2_diabetes
- **推荐要点**：
  - 血糖控制稳定且达标者：**至少每 6 个月**检测一次 HbA1c
  - 治疗方案有调整或未达标者：**至少每 3 个月**检测一次
- **产品中的使用**：HbA1c 复查模板默认每 3 个月（未达标场景，保守取值）
- **代码位置**：`KnowledgeBase.entries` id `diabetes.hba1c.monitoring`；模板 id `diabetes.hba1c`

### 1.3 2 型糖尿病：年度综合评估

- **来源类型**：临床指南
- **文献**：ADA Standards of Care in Diabetes—2025（第 4 章 Comprehensive Medical Evaluation）
- **组织**：American Diabetes Association
- **日期**：2024-12（DOI 10.2337/dc25-S004）
- **疾病**：type2_diabetes
- **推荐要点**：
  - **每年**一次综合医学评估：血压、血脂、肾功能（尿白蛋白/肌酐比、eGFR）、眼底、足部检查及并发症筛查
- **产品中的使用**：年度综合检查模板默认每 12 个月
- **代码位置**：`KnowledgeBase.entries` id `diabetes.annual.evaluation`；模板 id `diabetes.annual`

## 2. 引用核验方法

1. PubMed 检索（eutils，需代理）：`https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=...`
2. PMC 全文：`efetch.fcgi?db=pmc&retmode=xml&id=PMC<编号>`
3. 核实后再录入；记录 PMID / DOI / PMC 编号。
